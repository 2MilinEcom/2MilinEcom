# Hi, I’m Enrique

I build web applications, native iOS apps, and automation tools around practical problems—from reading and learning to content workflows and personal organization.

This profile collects my personal development projects. The repositories include source code, setup instructions, and implementation notes.

## Selected projects

- **[Bible Companion](https://github.com/2MilinEcom/bible-companion-portfolio)** — SwiftUI Bible reader with reading journeys, a companion chat interface, widgets, and a Python backend. Built with SwiftUI, Swift, Python.
- **[NextPlay Social Studio](https://github.com/2MilinEcom/nextplay-social-studio-portfolio)** — Video editing and social content workspace with caption preparation, approval, scheduling, and publishing adapters. Built with Python, SQLite, FFmpeg, JavaScript.
- **[VibeProof](https://github.com/2MilinEcom/vibeproof-portfolio)** — Product reviews application with merchant moderation, storefront widgets, and clearly labeled AI previews. Built with TypeScript, React Router, Prisma.
- **[Deal Finder](https://github.com/2MilinEcom/deal-finder)** — Native iOS deal discovery and receipt workflows backed by a Python API, caching, and offer verification. Built with SwiftUI, MapKit, FastAPI, SQLite.
- **[Bloom](https://github.com/2MilinEcom/bloom-cycle-tracker)** — Local-first iOS cycle and symptom journal with charts, device authentication, and explicit sharing controls. Built with SwiftUI, SwiftData, Swift Charts.
- **[Auto Work](https://github.com/2MilinEcom/auto-work)** — Career dashboard for application tracking, interview preparation, local drafts, and optional read-only inbox imports. Built with Python, JavaScript.
